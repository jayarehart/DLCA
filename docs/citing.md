# Citing

If you use DLCA in your work, please cite it. The citation metadata is in
[`CITATION.cff`](https://github.com/jayarehart/DLCA/blob/main/CITATION.cff)
at the root of the repository. GitHub's "Cite this repository" button, in the
sidebar of the [repository page](https://github.com/jayarehart/DLCA), reads it
and gives APA and BibTeX forms.

Please cite the version you used, and say which parameter set (`AR5` or
`AR6`) and time horizon your results use: both change the numbers.

The current `CITATION.cff`:

```yaml
--8<-- "CITATION.cff"
```
